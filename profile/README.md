## ✨ Ét samlet system

**Fileodon** giver organisationer et enkelt sted at administrere SFTP-forbindelser, navigere i filer og styre adgang.

- 🗂️ Godkend og administrér SFTP-forbindelser
- 📁 Gennemse, upload, download og distribuer filer
- 👥 Inviter brugere og administrér organisationsroller
- 🔐 Håndtér detaljerede rettigheder
- 🧾 Hold styr på organisationens handlinger med auditlogs
- 🖥️ Konfigurér Linux-servere gennem CLI'en og PAM-modulet
